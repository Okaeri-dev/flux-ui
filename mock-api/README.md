# Mock API - Next.js

This project is a Next.js application that serves as a mock API for the `flux` frontend application. It provides mock data for development and testing purposes.

## Project Structure

```
.
├── next.config.ts
├── next-env.d.ts
├── package.json
├── public
│   ├── file.svg
│   ├── globe.svg
│   ├── next.svg
│   ├── vercel.svg
│   └── window.svg
├── src
│   └── app
└── tsconfig.json
```

## Available Commands

The following commands can be run from this directory:

| Command | Description |
|---|---|
| `dev` | Starts the Next.js development server. |
| `pretty` | Lints and formats the code in this project. |
| `build` | Builds the Next.js application. |
| `start` | Starts the Next.js production server. |
| `lint` | Lints the code in this project. |
